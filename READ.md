# Expense Tracker with Data Analysis

A menu-driven Python application to track daily expenses and perform category-wise analysis.

## Features
- Add expenses (date, category, amount)
- View all expenses
- Category-wise analysis
- Percentage calculation
- Maximum, minimum, and average spending
- CSV-based data storage
- Modular Python design

## Technologies Used
- Python
- Pandas
- CSV File Handling

## How to Run
1. Install dependencies:
   pip install pandas
2. Run the program:
   python main.py
